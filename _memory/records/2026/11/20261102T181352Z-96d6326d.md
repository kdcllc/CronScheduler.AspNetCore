Pitfall: "make all NuGet deps current" via `dotnet list package --outdated --include-transitive` has traps in this repo layout (PackageReference Update items in build/dependencies.props imported by Directory.Build.targets).

1. --outdated suggests the newest version of ANY line — e.g. Microsoft.AspNetCore.Http.Features 2.3.x -> 5.0.17 (EOL .NET 5). Stay on the latest supported line and record the exception.
2. A transitive pin only takes effect if some csproj has a matching PackageReference Include; Update entries without an Include are dead (an evaluator caught two). Cross-check every Update id against Include ids.
3. Pinning sample/test transitives (~55 here) satisfies the check but needs monthly upkeep — consider Dependabot/Renovate or CPM transitive pinning.
4. Greps like "no Polly anywhere" break once Microsoft.Extensions.Http.Resilience (which depends on Polly.Core) is built — exclude obj/bin and target only the deprecated integration (Microsoft.Extensions.Http.Polly, Polly.Extensions.Http, using Polly;, AddTransientHttpErrorPolicy).
