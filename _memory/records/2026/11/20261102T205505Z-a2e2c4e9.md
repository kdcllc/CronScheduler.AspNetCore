Pitfall: after BackgroundService.StopAsync, ExecuteTask may end RanToCompletion (loop observes the token in `while (!stoppingToken.IsCancellationRequested)`) OR Canceled (token fires inside an awaited DequeueAsync). A test asserting `ExecuteTask.IsCanceled` passed every Release run and failed once in Debug QC. Assert `IsCompleted` (polled) and `!IsFaulted` instead. Also: always run the final suite in the default (Debug) configuration too — the CI/Release-only runs hid this race.
